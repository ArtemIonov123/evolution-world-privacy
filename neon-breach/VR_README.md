### Как устроен VR
1. **Одна поза головы** от NativeAR/ARCore (или обычная камера без AR). Вторая ARCore-сессия не создаётся.
2. **Две камеры**: левая `−IPD/2`, правая `+IPD/2` по **локальной горизонтальной оси головы** (с учётом поворота и наклона к плечу). Камеры параллельные, без сведения в одну точку.
3. **Проекция для каждого глаза** — асимметричная (off-axis): оптический центр кадра совпадает с центром линзы этого глаза.
4. Оба глаза рендерятся в одну текстуру (половина на глаз, внутреннее разрешение зависит от качества), затем **проход коррекции линз**: радиальная предкоррекция `r·(1 + k1·r² + k2·r⁴)` с отдельным центром для каждого глаза, пропорции 1:1 (без растяжения), за пределами кадра — чёрный.
5. **HUD для каждого глаза** (прицел, здоровье, патроны, цели, уведомления, меню VR) рисуется внутрь кадра глаза со стереосмещением, т. е. на глубине ~2,5 м, и проходит ту же коррекцию линз. Обычный HUD и большие сенсорные кнопки в VR скрыты.
6. VR включается и выключается **без перезапуска игры и ARCore**. CSS-поворотов нет, ориентация — нативная горизонтальная Android.

Без геймпада в очках: **тап по экрану** (кнопка очков) открывает меню VR, следующий тап — следующий пункт, **удержание 0,6 с** — выбрать. Пункт «ВЫЙТИ ИЗ VR» выключает VR, не вынимая телефон.

## 3. Калибровка VR-очков

1. ⚙ → **VR SETTINGS**. Включи **VR: ВКЛ** прямо в панели — изменения видны сразу.
2. **IPD** — расстояние между твоими зрачками (среднее 63 мм; можно измерить линейкой у зеркала).
3. **Межлинзовое расстояние** — расстояние между центрами линз очков (измерь линейкой, обычно 60–65 мм). Если у очков есть регулятор — выставь его так же, как IPD.
4. **Горизонтальное положение центров линз** — если телефон стоит в очках не по центру, сдвигай, пока обе картинки не станут симметричными.
5. **Вертикальное положение** — подними/опусти изображение до центра линз.
6. **Сила коррекции линз** — смотри на прямые линии стен: если они выгибаются наружу (бочка) — уменьши, если внутрь (подушка) — увеличь.
7. **Масштаб** и **угол обзора** — чтобы изображение заполняло линзы без лишних чёрных полей и выглядело в естественном размере.
8. Встань прямо, смотри вперёд, нажми **⊙ ЦЕНТР VR**. **СБРОС НАСТРОЕК** возвращает значения по умолчанию.
9. Качество (⚙ → Качество рендера): если FPS ниже 60 — СРЕДНЕЕ или НИЗКОЕ (меньше внутреннее разрешение, трекинг не страдает).

Все параметры VR и качество сохраняются между запусками.

| 1 | Обычный режим работает | ✅ сцена, HUD, без ошибок JS/WebGL |
| 2 | AR без VR (подставной NativeAR) | ✅ «AR: ТРЕКИНГ ARCORE», камера следует позе |

| 4 | Наклон головы не переворачивает мир | ⚠ по коду: поза берётся целиком из ARCore, смещение глаз по локальной оси головы; на устройстве не проверено |

## Безопасность
Режим скрытия изображения реальной камеры сохранён; физическая камера при этом продолжает работать для трекинга ARCore.
Игра **не** обеспечивает безопасную ходьбу в закрытых VR-очках и **не** определяет препятствия надёжно. Ходи только в свободном пространстве и под присмотром.
