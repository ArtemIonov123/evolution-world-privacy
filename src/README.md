# Isle of Legends — исходники

Игра собирается из этих файлов в **один** `index.html` (так быстрее грузится в Telegram).
Все `js/*.js` — один общий скрипт, склеенный по порядку из `index.html` (`@@include ...`),
поэтому функции и переменные из любого модуля видны во всех остальных.
**Порядок в `index.html` важен**: константы должны идти раньше, чем код, который их сразу использует.

Сборка: `./build.sh` (локально), `./build.sh web` (версия для GitHub Pages / бота).

## Структура

| Папка | Что внутри |
|---|---|
| `index.html` | каркас страницы и порядок модулей |
| `html/body.html` | разметка: HUD, кнопки, окна, чат, диалог |
| `css/base_hud.css` | основа, верхняя панель, сцена, окна |
| `css/editor_admin.css` | редактор карты и админка |
| `css/dialogs_mobile.css` | ник, диалог NPC, телефоны (вертикально/боком) |
| `css/bottom_hud.css` | нижняя панель (кнопки окон, дуга скилов, атака) |
| `js/core/boot.js` | спрайты, зона (остров/пещера), загрузка карты |
| `js/i18n/pl.js`, `ru.js` | все тексты на польском и русском |
| `js/core/lang_config.js` | язык, настройки из админки (CFG), всплывашки |
| `js/core/map_camera.js` | геометрия, клетки карты, камера и поворот |
| `js/core/hero_path.js` | герой, поиск пути, ходьба |
| `js/render/draw_world.js` | отрисовка блоков, порядок, лестницы |
| `js/render/rotate3d.js` | 3D-режим во время поворота |
| `js/render/hero_render.js` | рисование героя, рамка, главный кадр |
| `js/core/loop_input.js` | игровой цикл, мышь/пальцы, зум, кнопки, запуск |
| `js/world/*` | ветер, вода, рыбалка, купец, деревья, хижина и вход в пещеру, день/ночь, костёр |
| `js/world/zones.js` | свои острова и пещеры, переходы между картами, переход с подгрузкой карты |
| `js/npc/npc_dialog.js` | дед Богдан: спрайты, диалоги, задания |
| `js/items/rpg_gear.js` | уровни, снаряжение, ремесло |
| `js/items/custom_items_data.js` | свои и изменённые вещи из админки |
| `js/items/rods.js` | удочки |
| `js/ui/windows.js` | описание вещей, окна сумки/снаряжения/героя/заданий |
| `js/mobs/animals.js` | зайцы, волки, появление и ИИ |
| `js/mobs/custom_mobs_data.js` | свои мобы из админки |
| `js/mobs/bats.js`, `cave_boss.js` | летучие мыши, пауки и Голем |
| `js/mobs/bosses.js` | свои боссы: появление на своём месте, ИИ (удар по площади, призыв, ярость), респаун |
| `js/combat/*` | здоровье героя, бой и добыча, классы и скилы |
| `js/net/*` | мультиплеер, ники, обновления, присутствие, группы, сохранения, чат |
| `js/admin/*` | права админа, разделы, игроки, вещи, мобы, боссы, острова и переходы, фильтр ников, редактор карты |
