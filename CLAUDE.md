# Постапо-RPG — копия движка Isle of Legends

Это **отдельный проект**: копия кода изометрической пиксельной RPG «Isle of Legends» (Telegram Mini App),
из которой Артём делает игру в сеттинге **постапокалипсиса**.

**Где лежит:** репозиторий `ArtemIonov123/evolution-world-privacy`, **ветка `postapo`** (своя отдельная история).
Работать и коммитить **только в ветку `postapo`**: `git clone -b postapo --single-branch <repo>`.
Ветка `main` — это оригинальный остров (папка `island/`, сайт GitHub Pages и Telegram-бот) — **её не трогать**.
Если Артём позже создаст отдельный репозиторий — перенести туда эту ветку как `main`.

## Как работаем
- Артём пишет по-русски. Код пишет Claude, картинки рисует ChatGPT (GPT).
- **Пока без Telegram и без сервера**: после каждого изменения собрать `./build.sh` и отправить Артёму файл
  `game.html` на проверку (один файл, открывается в браузере без интернета, сохранение — в браузере).
- Промты для GPT: точные имена файлов для каждой картинки, **не больше 10 картинок** за один промт
  (GPT путается, если много сразу — дробить на небольшие наборы). Мокапы (примеры экранов) — с фоном.
- Каждый промт для картинок заканчивается блоком для GPT, как собрать ZIP:
  фон — сплошной маджента `#FF00FF`; **НЕ уменьшать** — оригиналы в исходном (крупном) размере;
  точные имена файлов; файлы в корне архива; в конце — ссылка на скачивание ZIP.
  (Уменьшение GPT до 64×48 через NEAREST давало «шумную» мутную картинку — уменьшаем сами.)
- Артём присылает ZIP → распаковать в отдельную папку (это чужие файлы), затем
  `python3 -I tools/import_art.py <папка>` — уберёт фон, впишет ровно на место старой картинки и сделает
  `sprites/<группа>/<имя>@2x.png` (двойное качество). Новые имена: `--size 64x48 --group props`.
  Потом вписать имена в `POSTAPO_ART` (`src/js/render/postapo_look.js`).
- **HD (@2x / @4x)**: кадр собирается сразу в разрешении экрана (`renderScale()` = zoomK в draw_world.js).
  `name@Nx.png` рисуется в том же месте и размере, что `name.png`, но в N раз детальнее; если есть — `name.png`
  в сборку не идёт (берётся самый детальный). Импорт: блоки и предметы — @2x, персонажи и звери
  (группы hero/npc/animals) — @4x (у GPT «пиксель» ~11 px, герой ~110 пикселей ростом — @4x сохраняет это).
  Логический размер (как в коде): блок 64×48 → @2x 128×96; герой 32×48 → @4x 128×192.
  Сильное уменьшение — выборкой из середины каждой клетки (медиана), а не усреднением: цвета чистые, контур чёткий.
  **Не копировать HD-картинки в canvas размером `im.width`** (это логический размер) — потеряют детальность;
  поэтому перекраска героя под цвет игрока (`heroSprite`) для HD-картинок отключена.
- **Блоки земли** (`block_*`) импорт подгоняет под сетку движка сам: верх-ромб растягивается точно на сетку
  (у GPT он бывает чуть площе), бок — ровно на высоту уровня (20 px в @2x), тёмный контур с верхней грани убирается
  (иначе на карте «сетка»). Тёмный край рисует движок только на обрывах (`drawCliffEdges` в draw_world.js) —
  для блоков из `POSTAPO_ART`.
- **Кадры анимации** (`hero_ne_0..3` и т.п.) импорт вписывает с одним масштабом и общей линией ног для всех кадров
  набора (иначе широкий шаг «уменьшает» героя). Присылать кадры одной анимации в одном архиве.

## Сборка и проверка
```
./build.sh                      # → game.html
npm i playwright --no-save      # один раз (Chromium уже есть в окружении)
node tests/smoke_test.js        # открыть игру, проверить, что нет ошибок (скрин: tests/smoke.png)
```
- `src/index.html` — оболочка со строками `@@include ...`; модули: `src/css`, `src/html`, `src/js/{core,world,mobs,combat,items,net,admin,ui,i18n,render}`.
- `tools/assemble.py` склеивает модули, `tools/build2.py` встраивает все `sprites/*/*.png` и карту `maps/island.json`,
  `tools/asciify.py` делает файл ASCII-безопасным.
- Тексты игры — `src/js/i18n/ru.js` и `pl.js` (ключи одинаковые).
- `tools/fake_rtdb.js` — поддельная база для тестов мультиплеера (пригодится позже).

## Сцена постапо (сделано)
- Карта — `maps/wasteland.json` (26×26, «Пустошь»): трасса, руины, ядовитый канал с мостом, лагерь с лачугой,
  Митяем и Барахольщиком. Начальная раскладка — `tools/gen_wasteland.py` (дальше правим в редакторе игры).
- `src/js/render/postapo_look.js` — пока нет нового арта, старые картинки острова перекрашиваются кодом
  (сухая трава, пыль, ядовитая вода). **Когда вставляешь картинку от GPT — впиши её имя в `POSTAPO_ART`.**
- Новые объекты `prop_car`, `prop_tires`, `prop_barrier`, `prop_bones` пока нарисованы кодом (`wind.js`, drawPropFallback);
  когда придут PNG с этими именами — встанут сами.
- Тексты (ru): пустошь, старик Митяй (сталкер), Барахольщик Сеня, псы, крысы, вороны, тараканы, Ржавый голем. `pl.js` ещё островной.
- `node tests/nick_test.js` — ник вводится и в «песочнице» без отправки форм (просмотр файла в приложении).
- `node tests/scene_shot.js` → `tests/scene_phone.png` и `tests/scene_wide.png` (вся карта).

## Что есть в движке (переиспользуем)
Изометрическая карта с высотами и лестницами, поворот камеры, зум; ходьба по клику; день/ночь, ветер;
бой ближний + классы (воин, друид) со скиллами на дуге справа; мобы (волк, летучая мышь, паук) и боссы;
лут, сумка на 30 мест с вкладками, снаряжение, крафт, костёр и готовка, рыбалка, рубка деревьев;
NPC с диалогами и заданиями, купец; острова/пещеры и порталы; нижняя панель HUD;
админка (редактор карты, вещей, мобов, боссов, островов, порталов, игроков).

## Локальный режим (сейчас)
- В `game.html` встроены `tools/fake_rtdb.js` (база в localStorage браузера) и `tools/local_adapter.js`
  (тот же интерфейс `claude.use("db"|"room"|"user")`, что у Firebase-адаптера острова). Мир — `postapo_wasteland_v1` (сменить имя = начать с карты по умолчанию).
- `window.__islandLocal=true` → игрок сразу админ: кнопка редактора и админка работают, всё сохраняется в браузере.
- Данные живут только в том браузере, где открыт файл (очистка браузера = потеря карты). Когда дойдёт до запуска —
  сделать экспорт/импорт мира в файл и перенос в настоящую базу.
- Язык по умолчанию — русский (`src/js/core/lang_config.js`).
- Тесты: `node tests/smoke_test.js`, `node tests/editor_test.js` (админ есть, правка карты переживает перезагрузку).

## Сервер (у острова, для постапо — сделать свой)
- Клиент — один HTML (GitHub Pages / Telegram Mini App). Данные и мультиплеер — **Firebase Realtime Database**
  (адаптер `island/src/build/fb_adapter.js` в main; здесь — `tools/local_adapter.js` с локальной базой).
- Бот — **Firebase Cloud Functions (Node.js 20)**, `bot/functions/index.js` в main: вебхук Telegram, кнопка «Играть»,
  токен в Secret Manager; вход по подписи Telegram → custom token Firebase (`__islandAuthUrl`).

## Важно
- Ключи localStorage/sessionStorage — с префиксом `pa_`, локальная база — `pa_frt:` (у острова `island_`/`frt:`): в Chrome все
  скачанные файлы делят одно хранилище, и общие ключи подмешивали в постапо сохранения острова (польский язык, пустая карта).
- Ошибки игры показываются красным окном на экране (`showGameError` в boot.js), игровой цикл после ошибки не останавливается.
- Игра публикуется и как артефакт «ПостАпо ГБН» (открывается прямо в приложении Claude).
- ID админа Telegram `1661222371` (Артём) — понадобится, когда подключим Telegram.
- Не коммитить токены ботов и ключи сервисных аккаунтов.
