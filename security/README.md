# Защита Isle of Legends

## Как устроено

1. Игрок открывает игру в Telegram. Telegram подписывает данные игрока (`initData`) токеном бота.
2. Игра отправляет подпись на наш сервер (`worker/` — Cloudflare Worker, бесплатно).
3. Сервер проверяет подпись и выдаёт пропуск в Firebase на `uid = utg<telegram id>`.
   Админу (Telegram ID из `ADMIN_IDS` в `worker/wrangler.toml`) в пропуск добавляется `admin: true`.
4. Правила базы (`database.rules.json`) пускают только с пропуском:
   - своё сохранение, свою запись игрока, своё присутствие в мире — только сам игрок;
   - настройки мира, карта, вещи, мобы, боссы, баны, кристаллы (`wallet`) — только админ;
   - общие вещи (деревья, костры, часы, смерть босса) — любой вошедший игрок;
   - чат — только от своего имени, чужие сообщения не изменить;
   - забаненный (`banned/<uid>`) ничего не может записать;
   - без пропуска нельзя ни читать, ни писать.
5. Тот же сервер — бот: `/start` и `/play` отвечают кнопкой «Играть».

Проверки: `tests/worker.test.mjs` (подпись, пропуск) и `tests/rules.test.mjs` (36 случаев на эмуляторе).
Запускаются автоматически в GitHub Actions → **Security tests** при каждом изменении папки `security/`.

## Что сделать один раз

### 1. Firebase: включить вход и скачать ключ
1. [console.firebase.google.com](https://console.firebase.google.com) → проект **island-6cbab**.
2. **Build → Authentication → Get started** (просто включить, провайдеры выбирать не нужно).
3. ⚙️ **Project settings → Service accounts → Generate new private key** → скачается файл `.json`.
   Этот файл — ключ от базы, никому его не показывай и не присылай в чат.

### 2. Cloudflare: аккаунт и токен (бесплатно, без карты)
1. Зарегистрируйся на [dash.cloudflare.com](https://dash.cloudflare.com/sign-up).
2. Открой **Workers & Pages** один раз — Cloudflare попросит выбрать имя поддомена `*.workers.dev`, согласись.
3. Справа на главной странице аккаунта скопируй **Account ID**.
4. **My Profile → API Tokens → Create Token → шаблон «Edit Cloudflare Workers» → Continue → Create Token** — скопируй токен.

### 3. GitHub: положить секреты
Репозиторий → **Settings → Secrets and variables → Actions → New repository secret**, четыре секрета:

| Имя | Что вставить |
|---|---|
| `FIREBASE_SA` | всё содержимое скачанного `.json` файла |
| `CLOUDFLARE_API_TOKEN` | токен из Cloudflare |
| `CLOUDFLARE_ACCOUNT_ID` | Account ID из Cloudflare |
| `TELEGRAM_TOKEN` | токен бота от BotFather |

### 4. Запустить выкладку
**Actions → Deploy server and security → Run workflow** (галочку `lock_rules` пока НЕ ставить).
Выложится сервер и настроится бот. Адрес сервера будет в итогах запуска — Claude впишет его в игру.

### 5. Закрыть базу
Когда игра с новым адресом сервера открылась в Telegram и всё работает — ещё раз
**Run workflow**, теперь **с галочкой `lock_rules`**. После этого база закрыта.

## Что остаётся
- Монеты, опыт и вещи хранятся в сохранении игрока, которое пишет сама игра. Очень опытный человек может
  подправить **своё** сохранение. Чужие аккаунты, мир и кристаллы ему недоступны.
  Полностью закрыть это можно, только перенеся бой и добычу на сервер — это отдельная большая работа.
- Кристаллы за Telegram Stars будет начислять сервер (следующий шаг) — подделать их нельзя.

## Кристаллы за звёзды Telegram
- Игра: кнопка «+» у кристаллов → окно «Кристаллы» (обмен на золото кнопками 2→100, 3→250, 5→600 с подтверждением, и пакеты за ⭐).
- Пакеты и цены — в `worker/src/index.js` (`PACKS`); в игре (`js/ui/crystals.js`) тот же список только для показа.
- `POST /invoice` создаёт счёт (`createInvoiceLink`, валюта `XTR`), бот в `/bot` проверяет `pre_checkout_query`
  и после `successful_payment` один раз начисляет кристаллы в `w/<WORLD>/db/wallet/utg<id>` (запись платежа — в `pay/<id>`, игрокам не видна).
- `POST /exchange` списывает кристаллы на сервере; золото игра добавляет сама.
- Заработает после запуска сервера (deploy-security) — пока сервера нет, покупка показывает «скоро».
